## Featured Projects

<details open>
<summary><strong>CareOps AI — Agentic Hospital Operations Copilot</strong></summary>
<br>

CareOps AI is a seven-agent operations platform that combines capacity forecasting, synthetic HL7 FHIR data, hospital policies, resource allocation, safety evaluation, and human approval into one decision-support workflow.

| Dimension | Details |
|-----------|---------|
| **Stack** | Python, LangGraph, Groq, Gemini, FastAPI, SQLAlchemy, Alembic, PostgreSQL, Redis, Qdrant, Next.js 16, TypeScript, Tailwind CSS 4 |
| **Scale** | Seven specialist agents; Patient, Encounter, Appointment and Observation resources; parallel operational planning |
| **Performance** | Parallel orchestration with retrieval and response quality evaluated through RAGAS, DeepEval and LangSmith |
| **Security** | Safety Critic, policy citations, human-in-the-loop approval queue and advisory-only operational guidance |
| **Impact** | Unifies capacity, staffing, bed and supply planning for emergency-surge, ICU-watch and shortage scenarios |

**Links:** [GitHub](https://github.com/shubhangini67/CareOps) · [Live Application](https://care-ops-liart.vercel.app)

The backend uses typed FastAPI services, SQLAlchemy persistence, Alembic migrations, PostgreSQL, and Redis. Policy-grounded RAG runs on Gemini embeddings with Qdrant Cloud deployed on AWS. A golden evaluation set tracks faithfulness, relevance, and retrieval behavior before recommendations reach the approval queue.

</details>

| Dimension | Details |

It pairs an XGBoost remaining-useful-life regressor with Isolation Forest anomaly detection over NASA C-MAPSS telemetry.

<details>
<summary><strong>Vision Transformer for IDC Detection</strong></summary>
<br>

A PyTorch Vision Transformer for detecting invasive ductal carcinoma from histopathology image patches, developed through systematic experimentation and held-out evaluation.

| Dimension | Details |
|-----------|---------|
| **Stack** | Python, PyTorch, NumPy, Gradio, Vision Transformer |
| **Scale** | 277,524 RGB histopathology patches derived from 162 whole-slide images |
| **Performance** | 90.27% test accuracy and 95.68% AUC, supported by precision, recall and confusion-matrix analysis |
| **Security** | Research-focused inference with no autonomous clinical diagnosis or treatment action |
| **Impact** | Demonstrates attention-based image classification and rigorous evaluation on a large medical-imaging dataset |

The project covers preprocessing, patch representation, positional encoding, self-attention, class-imbalance handling, overfitting control, model evaluation, and deployment through an interactive Gradio interface.

</details>

<details>
<summary><strong>Industrial Equipment Fault Detection — Edge AI</strong></summary>
<br>

An Edge AI platform for classifying bearing-fault conditions and detecting abnormal vibration patterns under resource-constrained inference requirements.

| Dimension | Details |
|-----------|---------|
| **Stack** | Python, Scikit-learn, TensorFlow, TensorFlow Lite, Streamlit |
| **Scale** | Five bearing-fault scenarios with supervised classification and unsupervised anomaly detection |
| **Performance** | FP32, FP16 and INT8 quantization with sub-millisecond on-device inference |
| **Security** | Local inference reduces external data transfer and supports privacy-preserving edge operation |
| **Impact** | Connects fault detection to rule-based CMMS recommendations and an operator-facing dashboard |

**Links:** [GitHub](https://github.com/shubhangini67/industrial-fault-detection-platform)

The system combines a Random Forest classifier with an Autoencoder anomaly detector, then packages inference through TensorFlow Lite variants to compare precision, model size, and latency trade-offs.

</details>
