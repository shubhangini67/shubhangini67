<br>

**Patient-Aware Vision Transformer with Explainability and Uncertainty Estimation for Invasive Ductal Carcinoma Detection**

| Dimension | Details |
|-----------|---------|
| **Stack** | Python, PyTorch, FastAPI, Gradio, Docker, Vision Transformer |
| **Scale** | 277,524 RGB histopathology patches · 162 patients · patient-aware grouped splits |
| **Architecture** | Memory-augmented ViT (128 learnable prototypes) + CNN/ResNet baselines |
| **Performance** | 90.27% test accuracy · 95.68% AUC · temperature scaling + MC dropout |
| **Explainability** | Grad-CAM · attention rollout · occlusion sensitivity maps |
| **Deployment** | FastAPI inference API · Gradio dashboard · Docker · Colab notebooks |
| **Impact** | Reproducible research pipeline with 22+ unit tests — not for clinical use |

**Links:** [GitHub](https://github.com/shubhangini67/PathoVision-) · [Colab Notebook](https://github.com/shubhangini67/PathoVision-/tree/main/notebooks)

Developed during research internship at **IIT (BHU), Varanasi** — covers preprocessing, patch representation, positional encoding, self-attention, class-imbalance handling (focal loss, balanced sampling), calibration, and rigorous held-out evaluation.
